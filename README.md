# MfE02/2026 ความก้าวหน้าครั้งที่ 1

สไลด์นำเสนอความก้าวหน้าครั้งที่ 1 ของโครงงาน "การออกแบบและปรับปรุงกระบวนการพับผ้าในโรงพยาบาล : กรณีศึกษา" (งานจ่ายผ้ากลาง โรงพยาบาลสงขลานครินทร์)

## การใช้งาน

เปิด `index.html` ในเบราว์เซอร์ สไลด์แสดงทีละหน้าเต็มจอ

| ปุ่ม | การทำงาน |
|---|---|
| ลูกศรขวา ลูกศรลง Page Down หรือ Space | หน้าถัดไป |
| ลูกศรซ้าย ลูกศรขึ้น หรือ Page Up | หน้าก่อนหน้า |
| Home และ End | หน้าแรก และหน้าสุดท้าย |
| B | ไปหน้า Backup (หน้า 20) |
| F | เปิดหรือปิดเต็มจอ |

- หน้า 1 ถึง 19 เป็นหน้าที่นำเสนอ (หน้า 13 ถึง 17 เป็นข้อเสนอแนะจากการสอบความก้าวหน้าครั้งที่ 1) หน้า 20 เป็น Backup หน้า 21 ถึง 23 เป็นหน้าหัวข้อของรายงานความก้าวหน้า ใบตอบคำถาม SO และใบสรุปโครงงาน และหน้า 24 ถึง 95 เป็นหน้าคำอธิบาย
- ข้อความที่ขีดเส้นใต้เป็นลิงก์ไปยังหน้าคำอธิบาย ทุกหน้าคำอธิบายมีลิงก์กลับหน้าที่อ้างถึงและลิงก์ไปหน้า Backup
- ลิงก์ตรงไปยังหน้าใดหน้าหนึ่งใช้รูปแบบ `index.html#p05` (หน้า 5)
